# Amor de Quatro Patas

Site desenvolvido para uma ONG fictícia de proteção animal como parte da disciplina de Desenvolvimento Front End, do curso de Análise e Desenvolvimento de Sistemas (ADS), da Universidade Cruzeiro do Sul.

## Sobre o projeto

A aplicação apresenta informações sobre a ONG, seus projetos e ações, além de disponibilizar um formulário para cadastro de voluntários.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript Vanilla, com organização modular utilizando ES6 Modules.

## Funcionalidades

- Navegação entre páginas utilizando SPA e History API;
- Componentes reutilizáveis;
- Formulário de cadastro de voluntários;
- Máscaras para CPF, telefone e CEP;
- Validação dos dados do formulário;
- Validação de idade mínima de 18 anos;
- Persistência dos dados utilizando `localStorage`;
- Feedback visual utilizando Toast;
- Gráfico de ações utilizando Chart.js;
- Layout responsivo.

## Tecnologias
